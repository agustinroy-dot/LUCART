## 2024-05-19 - AppSetting caching and untracked files
**Learning:** `AppSetting` is used extensively in forms to retrieve global configuration dynamically, but reading from the DB every time created large N+1 situations. Adding request-level caching with `flask.g` speeds this up significantly. Ensure testing local caching mechanisms with a proper `test_request_context` to avoid crashes. Additionally, caching database instances (`instance/*.db`) and compiled bytecode (`__pycache__/*`) into version control must be strictly avoided. Use `.gitignore` and `git rm -r --cached .` to un-track binaries prior to submitting performance patches.
**Action:** Request-level caching is highly effective for global app settings. Ensure binary and instance files are purged from the staging area.
