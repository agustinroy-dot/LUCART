## 2024-03-23 - [Eliminate N+1 Queries in Order View]
**Learning:** When displaying details for a complex entity like an Order with multiple relationships (items, materials, and nested relationships like OrderMaterial->Material), lazy-loading triggers N+1 database queries. Furthermore, relationships defined with `lazy='dynamic'` are incompatible with `joinedload` eager loading; they must be changed to `lazy='select'` (or default) to enable optimization.
**Action:** Replace `lazy='dynamic'` with `lazy='select'` in the model definitions and use SQLAlchemy's `.options(joinedload(...))` in the route to eager-load all required relationships in a single query, significantly reducing database roundtrips. Ensure templates use `|length` instead of `.count()` when switching from dynamic to select loading.
