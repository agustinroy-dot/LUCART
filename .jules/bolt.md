## 2024-05-19 - SQLAlchemy N+1 Queries in Flask Views
**Learning:** The `/quotes/` view in Flask apps frequently triggers an N+1 query problem when iterating over queries to access relationship data, such as `quote.customer.name`. Using `joinedload` on relationships is a highly effective way to address this, reducing 100+ queries to just a couple. Furthermore, ensuring temporary testing and benchmarking scripts are deleted, and no unrelated template files are modified during performance improvements, is critical for clean pull requests.
**Action:** Always check loop contents in Jinja templates (e.g. `{% for item in items %}`) for accessing related fields. When they do, update the corresponding `route.py` file to include `joinedload` to eager-load those fields. Make sure to delete scratchpad scripts after use.
